# Lista de exercícios 1 - Estruturas de decisão

#### Restrições
- Sem frameworks
- Sem OOP
- Sem firulas mirabolantes maquiavélicas
- Entrada de dados via teclado
- Não é necessário validação de dados
- ~~1 Classe diferente para cada exercício~~

>Essa foi a primeira atividade de algoritmos, portanto foi solicitado pelo professor 
> que cada exercício da lista fosse um arquivo separado, como estou reprocessando 
> o material, irei optar por construir a lista em uma única classe monolítica, com 
> cada exercício separado em procedimentos (métodos sem retorno).
--- 

1. Peça um número inteiro e informe se ele é par ou ímpar, se ele é múltiplo de 3, e se ele é divisível por 5.

2. Leia um número e informe se ele é positivo, negativo ou zero.

3. Peça dois números e informe qual é o maior.

4. Solicite três números e mostre qual é o maior.

5. Peça a nota final do aluno e informe se foi aprovado (nota ≥ 7) ou reprovado.

6. Solicite a idade de uma pessoa e diga se ela pode se aposentar (idade ≥ 65).

7. Leia um número e informe se ele é múltiplo de 5.

8. Verifique se um número é divisível ao mesmo tempo por 3 e por 4.

9. Peça a idade de uma pessoa e diga se o voto é obrigatório (entre 18 e 70 anos).

10. Solicite três lados e verifique se formam um triângulo válido. (Soma de dois lados deve ser maior que o terceiro)

11. Se for triângulo válido, diga se é equilátero, isósceles ou escaleno.

12. Dado o valor da compra, aplique:
	- 10% de desconto se for maior que R$500
	- 5% se for entre R$200 e R$500
	- nenhum desconto se for abaixo de R$200

13. Leia três números e mostre-os em ordem crescente (sem usar sort).

14. Converta uma nota numérica (0 a 10) para conceitos:
	- A (≥9),
	- B (≥8),
	- C (≥7),
	- D (≥6),
	- E (<6)

15. Peça dois números e uma operação (+, -, *, /). Execute a operação.

16. Peça três números e informe se o terceiro é igual ao primeiro ou ao segundo.

17. Informe se dois números têm a mesma paridade (ambos pares ou ambos ímpares).

18. Verifique se um ano é bissexto (divisível por 4, mas não por 100, exceto se divisível por 400).

19. Leia peso e altura e classifique o IMC como:
    - Abaixo do peso (<18.5)
    - Normal (18.5 a 24.9)
    - Sobrepeso (25 a 29.9)
    - Obesidade (30 ou mais)

20. Classifique um número em positivo ou negativo, par ou ímpar, e inteiro ou decimal.

21. Implemente um programa que exiba um menu com opções de café da manhã e o usuário deve escolher uma opção (1 - Pão com manteiga, 2 - Café com leite, 3 - Suco de laranja, 4 - Omelete). O programa deve exibir a escolha feita.

22. Crie uma calculadora simples que permite ao usuário escolher entre soma, subtração, multiplicação ou divisão. O programa deve pedir dois números e realizar a operação escolhida.

23. Crie um programa onde o usuário deve escolher um tipo de transporte (1 - Carro, 2 - Bicicleta, 3 - Ônibus, 4 - Avião) e o programa exibe a velocidade média do transporte escolhido.

24. Crie um programa que converta um valor informado pelo usuário de uma moeda para outras moedas (por exemplo: 1 - Dólar, 2 - Euro, 3 - Real). O programa deve mostrar o valor convertido com base na cotação atual.

25. Implemente um programa onde o usuário escolhe uma figura geométrica (1 - Círculo, 2 - Quadrado, 3 - Retângulo) e o programa pede as medidas necessárias para calcular a área da figura escolhida.
