# java

Projetos e exercícios em Java, separados por origem.

## Estrutura

- `faculdade/` — um projeto IntelliJ por disciplina
- `externo/` — cursos e projetos pessoais fora da faculdade

Dentro de cada projeto da faculdade, o código é organizado em packages por tipo de atividade:


- `listas/` — exercícios das listas passadas pelo professor
- `provas/` — provas e avaliações escritas em código
- `testes/` — testes e experimentos próprios pra praticar conceitos
- `aulas/` — código escrito durante ou logo após a aula, acompanhando a explicação do professor

Cada exercício pode conter um `.md` com o enunciado ao lado do `.java` correspondente.
